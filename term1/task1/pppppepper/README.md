# 见天地，见众生，见自己

所选领域：网络文学
作品名称：天官赐福
作者：墨香铜臭
作品链接：https://www.jjwxc.net/onebook.php?novelid=3200611

## 个人感受
这本小说是在我很早很早之前就听说过了，无论是从网络上、朋友推荐，还是在谷子店里的周边，都有它的影子。在完成了这本小说的阅读之后，给我最大最直白的感受就是----这小说火是有它的道理的！！！无论是作者的世界观、文笔、小说的叙述方式，还是书中塑造的人物形象，都非常非常地令我震撼。我认为一本好的文学作品，它是能真正打动人的内心，影响读者对于这个世界的看法和处事的态度。全书长达一百多万字，每个情节都环环相扣，不只有主人公之间的爱情，更是作者在字里行间和读者们一起探讨世界的善与恶、道与情、法与理，让人读完了还是意犹未尽。所以我认为这是一部可以反复琢磨研究细节的非常优秀的网络文学小说。
## 专业分析
- ### 独特的叙述方式
本书采用双线叙事，作者不是完全按照顺叙而展开，而是在第二卷和第四卷时穿插了对过去的回忆，不仅使人物的形象更饱满，还让对应了一些可能未曾注意到的细节，当读者带着过去的情节再仔细品读时，或许会恍然大悟，对角色当时的立场和选择有了更深的理解。而这种穿插回忆录的方式也是这个作者具有特点的写作方式之一。她在后记中说过：
> 故事是性格的历史，也是性格的谜底。一个有故事的人站在我面前，就像一道谜底。解开这个谜的办法就是了解他的故事。因为正传所以好奇想要了解喜欢的角色的过去，因为过去更爱现在的他。

因为故事，一个个书中的人物不再是单一的面貌，得以跃然纸上，变成鲜活的“人”，也因为故事，让读者而为之喜悦、为之遗憾、为之悲伤。
- ### 文笔赏析
对于一个只写了三本小说但本本都爆火的作者来说，文笔功底自然是非常强的。而《天官赐福》更是被读者普遍认为是该作者笔力的巅峰。语言该浓则浓该淡则淡，叙事效率高，节奏把握得当，强悍的写作功底构成了《天官赐福》的基石。如每一篇的标题都是以文言形式来取的：
![天官目录](images/微信图片_20261023204808_182_4.jpg)
八字标题精简对称，不仅准确概括出该篇章的中心思想，更能从字里行间让读者体会到每个人物的内心的细腻情感。

以一个标题为例----“本玉质哪甘作砖抛”。这是一个我很喜欢的标题。其中融入了成语“抛砖引玉”，字面上的意思是抛出劣质的砖头从而引出美玉。而这个标题对应的故事是一位名为引玉的武神。他武力超强、勤奋刻苦，本该在众神官中是佼佼者的存在，可只因自己的师弟中出现了一个千年难遇的天赋奇才而被人忽视。引玉是个极善良的人，他不愿有天赋有能力的人被埋没，主动引荐师弟，但又不甘心自己多年努力的结果被人看轻。明明身为美玉，却被人视为平庸，一个“哪甘”生动传神地传递出了人物内心不甘、遗憾、无奈的情感，本玉质哪甘作砖抛，可“引玉”这个名字，似乎一早就为他写好了结局。

再看一个文段新旧版的对比：
旧版：
> 桌有四方，这两人一左一右，各占一方，两边都是十八九岁的少年，左边的更高，眉目颇为深邃明俊，目光之中带一股桀骜不驯。右边的极白，清秀且斯文，只是神色有些过于清冷淡漠了，仿佛心里不太痛快的样子。事实上，两人脸色都不太好看。

新版则简略了外貌描写：
> 桌有四方，这两人一左一右各一方。两方都是十七八岁的少年，都是一股黑云罩顶。
左边那少年桀骜，道：“南风。”
右边那少年斯文，道：“扶摇。”

这段话没有华丽的辞藻，但是里面有两点细节的改动值得我们学习。一个是叙述视角的转换：旧版用的是全知视角，是作者硬塞给读者的外貌描写，主要的叙事功能就是告诉读者这两个人长什么样；而新版则是代入了角色视角，这是主角谢怜对他们的第一印象，用词精确，带有情绪色彩，直截了当地告诉读者对面两人的人物性格特点。第二个则是从外貌描写到角色对话的转变。这段话比起外貌，更重要的是对面两人传递的情感。对话的形式句式整齐、节奏明快，让读者读起来更顺畅的同时，还让人物形象的刻画更生动。
- ### “人上为人，人下为人”----东方玄幻小说中蕴含的哲学观
这本小说的核心之一，就是对传统神权进行“祛魅”。在众多人对于神鬼的观点中，可能认为“人往上走，成神；人往下走，成鬼。“，但在作者看来：
> “往上走，还是人；往下走，依旧是人。”

接合整篇小说来看，文本中反复强调，神的法力来源于人的供奉，没有信徒就没有法力。中国的神佛不讲血统传承，讲的是功德圆满，百姓信仰。这正是历史唯物主义里的核心观点：不是神创造了人，而是人创造了神；不是少数的英雄创造了历史，而是众生的合力撑起了时代的天空。而这本小说所有的角色都在演绎”人上为人，人下为人“这句话。神和鬼依旧摆脱不掉人性，好坏都有，善恶同在。无论外表包装如何，本质都是人，都有七情六欲，喜怒哀乐，低处的人不一定比高处坏，而高处的人不一定比低处好，正如天官里所写的，有的神官会为了自己弟弟能顺利飞升而偷换普通人的命格，而令人害怕避之不及的众鬼却会在百姓最需要帮助的时候来到人间。神有人欲，而人欲万种；苍生百态，从来不能被某个词完整概括。人物塑造是文学中很重要的内核，而这本小说中的每个人物形象都是非常立体饱满的。
- ### “身在无间，心在桃源”
北大网文文坛曾经这样评价《天官赐福》：
> 《天官赐福》是写给那些出生在最好的年代、幸福顺遂长大的孩子们的寓言： 总有一天，你会走出堡垒、看见这个世界，看见世上的人远比你想象中要复杂、混沌、平庸卑劣。而你毫无疑问也是他们中的一员，你们都会矛盾胆怯、彷徨困顿、自我怀疑、甚至满心怨恨。但你曾经相信，并仍旧渴望相信的那一切----尽管幼稚，却也伟大。

这是一本写给成年人的童话。天官中，主角之一谢怜是一位热爱苍生并想要拯救苍生的神官，“身在无间，心在桃源”便是他的真实写照。虽然在经历被苍生一次又一次的伤害背叛后，他也曾迷茫憎恶，认为自己幼稚愚蠢的理想主义太过堂皇。但就在他心灰意冷即将迈向不该走的道路时，一位曾经骂过他的平民在雨中为他送来了一顶雨笠----“渊中人得一雨中笠，雨中笠可抵命中敌”。仅仅一顶雨笠，就让他重拾希望，主动把自己所有的气运散给苍生。此后的八百年里，永远倒霉、孤苦伶仃、穷酸潦倒，却甘之如饴。

这并不是一个告诉读者世间不配的故事，恰恰相反，它在全面的教会你如果正确地看待这个世界。人之初，性本善。初入这个社会的我们，或许都像谢怜一般是个“理想主义者”，都对这个地球online怀有无尽的热情与友善，但随着遇到的人、遭遇的不公越来越多，我们难免会对这个世界产生失望与埋怨。但是我们并不能改变别人，能改变的只有我们自己对这个世界的态度----见苍生、救苍生、悟苍生。依旧为那些心怀期待的人们、依旧为曾经那个幼稚却也伟大的自己坚持着。

## 未来展望
我认为一部好的文学作品，应该有优美的文笔，叙事节奏不拖沓。而在编写一些作品文案、游戏故事线时，也应该做到这些。用精简准确的语言、详略的取舍、留白的分寸来传达故事情节与人物情感，让叙事更高效，为整体添砖加瓦。同时也可以采用插叙的叙事手法，让情节波澜起伏，让玩家深入其中。
- ### 过去和现实的切换
双线叙事是天官的叙事特点之一，而作者在过去与未来的衔接上，我觉得有两点是值得我在文案或者游戏叙事中学习的：
1. 通过关键物品或特定场景来引发回忆。天官中，有很多这样的案例，如看到珊瑚珠想到昔日身为太子时的风光等。这样能够强调关键物品对于过去和现在之间的重要性，同时加强二者之间的联系，也使得引发回忆时的过渡自然。
2. 运用相同的语句来实现时间线的切换。举一个小说中的案例：
> 不多时，那道红衣身影便在山前、月下、在谢怜的眼中，消失无踪了。只有一朵小小的白花，悠悠飘落。（这是现在）
那朵白花飞过漫天飘舞的彩带和欢呼，落于一剑。（这是过去）

这样的叙事手法，使得读者还沉浸在某一时间线中的剧情时，自然而然地过渡到另一条时间线中----我当时读到这的时候是非常非常震撼的！没想到不用画面，单单凭文字就可以达到这种过渡自然的效果，在游戏中写文案时，我认为也可以用这个手法。
- ### 用冰川法则来让故事变得更刺激
在编写游戏中，可以通过隐藏关键信息，并选择在最佳时机揭露，来让情节变得波浪起伏，吸引玩家的兴趣，甚至通过游戏里人物的对话等来特地引导玩家往错误的方向想，然后等揭露真相的时候震惊玩家。如天官中，国师指着谢怜的方向说幕后主使就在这里，而一切的线索似乎也是指向他。就当读者也被带跑时，能照出妖魔的剑却映射出了一张藏在谢怜身后的脸----那是众人们从未怀疑过的，主持天庭一切的老大君吾
- ### 三幕式结构法
前面两个启发说的都是写法，我这里还学习到了叙事的结构。
这里我借鉴了小红书博主"从零开始的写作之旅“的分析（https://xhslink.cn/o/49n7Q31ajzE）。
天官中的三幕式结构分别是建置、对抗、解决，来推动剧情发展；而九线（命运、情感、权力、悬疑、成长、文化、喜剧、伦理、时间诡计）在其中交织，构建复杂叙事。在讲这个叙事手法借鉴到游戏设计中，也可以采用三幕式的结构，将世界观构建、悬疑铺垫等转化成玩家可以交互体验的游戏：
1. 第一幕：建置（20%-25%）- 新手村与世界观的导入：搭建世界观的底层逻辑，确立主角的核心目标，给玩家一个关于这个世界的基本框架（如天官中阐述了人鬼神三界，四大害和四名景，主人公的目标是拯救苍生）。同时也可以隐藏一些线索，埋下伏笔。如天官开篇介绍背景时潦草一笔带过了四大害之一“白衣祸世”，最后才发现这是整本小说的终极大boss。
2. 第二幕：对抗（50%-60%）- 主线推进与副本挑战：通过矛盾的冲突升级，解开一个个看似无关却紧密相连的支线谜团，进而推动剧情发展。其中可以加入回忆的故事线，让玩家通过过去了解更多，使得谜团扑朔迷离，为最后的高潮做准备。
3. 第三幕：解决（15%-20%）- 终局之战与真相大白：将所有的线索和谜团指向最后的真相，引爆终极矛盾，填完所有的坑，达到整个剧情的高潮与升华。
